# C++ Qt上位机

机器人关节伺服驱动与安全控制平台的桌面工作台，采用 C++17、Qt Widgets、QSerialPort 和 QCustomPlot。

## 页面与流程

- **设备监测**：设备信息、MCU状态、反馈曲线与采样点读数。
- **测试任务**：草案配置、能力校验、有限步骤执行与同号结果。
- **记录回放**：历史曲线、执行结果、原始日志核对及CSV/JSON导出。
- **设备维护**：串口字节转换、收发预览和诊断记录。

串口由单一所有者维护；任务许可、保活、停止和回执关联由独立控制器协调。运行程序使用C++实现，Python仅用于开发阶段的协议参考和夹具生成。

构建与运行命令见[项目README](../../README.md)，F1打开[完整手册](USER_GUIDE.md)。离线演示使用[确定性合成数据](tests/FIXTURES.md)。
