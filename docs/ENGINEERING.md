# 工程说明

## 工具职责

CubeMX维护芯片、引脚、时钟与外设配置；Keil负责固件构建、链接和下载；业务模块与主机工具通过源码维护。

当前FreeRTOS控制/串口任务在USER CODE区域配置，再生成前需保留现有任务及共享资源安排。

## 当前样机接口

- STM32F407、CAN1 1 Mbps、C620 ID1反馈0x201、控制槽位0x200。
- USART6 115200 8N1，固定长度UART任务、状态、遥测和操作会话协议。
- 电流命令使用raw，编码器使用raw计数，转速使用rpm，温度使用摄氏度。

## 样机操作

现场操作前核对供电、参考地、CAN线序与终端、机械固定、限流、急停和快速断电。下载、真实串口和运动测试由操作者显式启动；配置/构建、板上运行、外部通信和闭环测试分别记录。

原始现场证据保存在私有研发资料中；公开仓库的回放样例为合成数据。C620内部FOC与STM32的任务、安全及上层控制职责分别描述。
