# 平台路线

## FOC与当前执行链

当前样机使用C620集成FOC电调与M3508电机。FOC电流执行位于C620；STM32负责CAN命令、反馈解析、许可校验、限幅/期限、会话与本地安全状态；C++ Qt负责计划、操作、曲线、回放和结果记录。

```text
C++ Qt测试计划 → STM32本地许可与安全执行 → CAN命令 → C620集成FOC → M3508
                       ↑                                    ↓
                  状态与结果记录 ← CAN反馈与停止回执 ←───────────┘
```

## 软件平台的扩展规划

| 层级 | 目标 | 核心工作 |
|---|---|---|
| 设备适配 | 多厂家厂商CAN与CANopen/CiA 402 | 设备识别、能力描述、报文/量纲映射、速度/位置/转矩模式与故障语义，逐型号建立兼容矩阵 |
| FOC设备执行 | 集成FOC的一体式电机/驱动器 | 按设备公开协议接入电流、转矩、速度或位置能力，保留各设备的单位、范围和停止方式 |
| 网络链路 | W5500 TCP | 任务、遥测、设备维护和连接生命周期与控制器安全策略协同 |
| 持久化 | W25Q256 / AT24C256 | 配置、校准、参数版本、事件与实验记录，确定容量、掉电一致性与恢复方式 |
| 固件维护 | 控制器IAP/Bootloader与A/B失败回滚 | 镜像校验、启动确认、升级中断、损坏和掉电恢复 |
| 控制与测试研究 | 上层PID、速度/位置外环、阶跃/斜坡与零位 | 在已明确的反馈、量纲、周期、执行器约束下设计和验证 |
| 应用交付 | 有限自动测试、EOL场景及报告 | 根据样机、工装、测量条件和判据定义测试项目与可追溯结果 |

## 推进顺序

1. 收口现有C++ Qt与STM32链路，完成受影响的现场回归。
2. 建立公共适配接口、设备能力描述与兼容矩阵，扩展厂商CAN和CANopen设备。
3. 接入TCP与持久化，完善任务、记录和维护链路。
4. 完成控制器升级与恢复机制；按设备和应用需要开展控制外环及测试项目研究。

本文件记录完整产品演进方向。当前源码入口与本次软件验证结果分别见仓库README和docs/VALIDATION.md。
